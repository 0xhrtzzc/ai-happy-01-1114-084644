# Entry for make.fun's ai-happy-01

`main.py` writes the entry image to `/output/entry.png`; the picture sits beside it as `entry.jpg` and is copied byte for byte.

The picture is a child's card taped to a fridge, addressed to the judge: candidate poems and cards were compared and this is the one kept. The drawing is made with Pillow, the handwriting is rendered letter by letter.
